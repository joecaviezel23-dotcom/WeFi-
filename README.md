# WeFi Site Recreation

An independent, responsive recreation of the public WeFi landing page using static HTML and CSS. It is not the official WeFi website.

## Preview locally

Open `index.html` in a browser or serve this directory with any static file server.

## Publishing

The `Deploy to GitHub Pages` workflow publishes the site on pushes to `main` and can also be started manually from the Actions tab.

Before the first deployment, a repository administrator must enable GitHub Pages for this repository and select **GitHub Actions** as the build and deployment source in **Settings → Pages**. The workflow cannot change this repository setting with its automatic token. After Pages is enabled, rerun the workflow from the Actions tab or push a change to `main`.

The expected project-site URL is <https://joecaviezel23-dotcom.github.io/WeFi-/>.
